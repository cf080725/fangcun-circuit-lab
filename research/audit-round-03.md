# 第 3 轮审查：元件外观、参数和接点一致性

日期：2026-11-06  
范围：`dist/workbench.js`、`dist/workbench2d.js`、`dist/model-renderer.js`，以及模型回归测试。未修改求解器、板卡配置、主界面或商城。

## 审查发现与实质修改

| 发现的真实问题 | 修复 | 对使用者的影响 |
| --- | --- | --- |
| 两个渲染器各自把阻值四舍五入成两位数字；999 Ω 会溢出为黑、黑、棕。0 也会被 `|| 330` 改成 330 Ω。1234 Ω 的标签与色环分别表示不同数值。 | 新增共享 `resistorVisual()`。可精确用两位有效数字表示时用四环，三位时用五环；999 Ω 画白、白、白、黑、棕。1234 Ω 等不能精确编码的输入直接印字，不伪造近似色环。0 Ω 绘图采用单黑环，非法值明确显示未知标记。 | 改阻值后，色环、标签和提示保持一致，不会教错读环方法。色环公差只做外观示意，提示说明求解器不模拟公差。 |
| 电位器标签固定为 10kΩ；电容 0 容量被标签回退成 100µF；元件参数没有统一单位格式。 | 共用 `formatResistance()`、`formatCapacitance()`、`componentLabel()`。电阻、电位器、电容展示元件 ID 和实际参数；自动显示 Ω/kΩ/MΩ、µF/nF/pF/mF，消除单位换算的浮点尾数。 | 读图即可辨认检查器中正在编辑的元件与数值，避免外观仍停留在默认值。 |
| 蜂鸣器和电容的 3D 接点在壳体下方 z=0，而 SVG 接点在外露引线末端；SVG 若干引线用近似像素，末端与可点击点不完全重合。 | 新增 15 类器件共用的 `componentPins()` / `componentPin()`；两个视图从同一局部坐标表注册接点。蜂鸣器、电容改成外露弯脚；电位器、LDR、NTC、电机、电源引线按相同坐标画到端点。 | 切换视图后，同一导线仍接到相同外露脚，视觉接点不再躲在壳体内。坐标单位为 cm。 |
| LED 只写很小的 A/K，缺少阴极平边；电容 3D 负极条纹反而位于正极那侧。 | LED 增加阴极平边、明确 A + / K − 文字，并保留长、短脚区别；电容条纹移到负极侧。 | 新手能同时用极性文字和外形识别引脚，不能只凭颜色猜测。 |
| Blue Pill 独立硬编码 PCB 2.28×5.33、针排 x=±1.016，与当前 profile 的尺寸和针位存在偏差。 | PCB 尺寸、40 个针脚坐标和丝印都使用 `boardVisual(profile)` / profile.pins；其他八种板沿用同一几何契约。 | 图形与可接线端点不再有两套数据来源。轮廓依然标为教学近似，不冒充制造 CAD。 |
| 俯视 PCB 没有边缘层次；USB 外壳缺少折边、焊接耳细节；3D 开关拨杆更新时只有银杆移动，红帽留在旧位置。 | 增加 PCB 基材边缘、USB 金属折边和固定焊耳；将开关银杆、红帽放入同一个移动组。 | 外形层次更清楚，动态零件保持整体移动。金属外观不会新增任何虚构的电气端点或 USB 协议能力。 |

## 验证

- `node --check`：三个渲染模块均通过。
- 新增 `tests/renderer-models.test.mjs`，**8 项通过**：色环独立反解、999 Ω 边界、不能精确编码的输入、零值和非法值、真实参数标签及单位、全部器件接点名称/坐标、极性与外露引线、未知模块接口、九种板的全部针位契约。
- 色环测试使用中文色名的独立反解，验证实际阻值，未只比较实现函数的内部字段。
- SVG/Three.js 都接入共享坐标；这是源代码与纯几何验证。实际浏览器的清晰度、遮挡和点击体验由根代理统一执行 QA。
- 本轮未声称完成 WebGL 视觉验证：此前实际环境未提供可用 WebGL，3D 部分只有语法与几何检查。

## 边界

- **0 Ω 仅验证绘图函数**。平台允许哪些参数由主界面验证与求解器决定；当前平台不因此新增可运行零欧电阻支持。
- 四环/五环的公差色仅用于识别练习，不加入随机误差、温度系数或真实元件制造偏差。
- 引线使用便于教学和连线的外露弯脚姿态；不是可直接送 PCB 制造的封装落脚图。
- PCB、接插件、镀层和塑料仍为程序化几何与材质；没有用照片掩盖针位，也没有增加未模拟的 I²C、SPI 或 USB 功能。

## 官方参考

- [Vishay 电阻色环表](https://www.vishay.com/docs/49411/resistor_color_code_calculator.pdf)：四环/五环的有效数字、乘数和公差标记。
- [Vishay FRJ 零欧跳线数据表](https://www.vishay.com/docs/31016/frj.pdf)：单黑环标记；该旧器件已停产，这里仅用作标记参考，不作选型推荐。
- [Kingbright WP7113ID 5 mm LED 数据表](https://www.kingbrightusa.com/images/catalog/SPEC/WP7113ID.pdf)：参考封装尺寸及极性识别；教学几何并未声称逐尺寸复刻该型号。
- 板卡轮廓与接口位置沿用 `board-profiles.js` 和 `model-renderer.js` 记录的 Arduino、Espressif、Raspberry Pi、ST 官方资料；本轮不修改这些电气映射。

## 提供给其他界面的共享接口

`resistorVisual(partOrValue)` 返回 `value`、`label`、`mode`、`bands`、`note`；每条 band 有 `color`、`name`、`kind` 及对应 `digit` / `exponent` / `percent`。商城可直接复用，避免再次出现独立且不一致的色环算法。公开工作台构造与回调 API 本轮保持不变。
