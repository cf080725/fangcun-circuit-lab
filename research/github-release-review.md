# GitHub 发布候选包十轮验收

候选包基于私有站点 v10.38 源码 `94b6b02`。验收使用独立目录，开发板与电路的实测结果均来自候选包在浏览器内的仿真。

| 轮次 | 检查与处理 | 验证结果 |
| --- | --- | --- |
| 1. 公开副本 | 旧仓库历史、私有部署配置、10 份厂商 PDF 及 PDF 原文预览截图退出发布目录。 | 独立目录保留网页、固件、Blender 脚本、测试和公开来源说明。 |
| 2. 本地启动与署名 | 补充启动命令、板型及固件范围，集中列出照片、CAD 改作和依赖的许可。自有源码许可由权利人决定。 | 按 README 运行 Python 静态服务器，首页、JS、GLB、WASM 和资料索引均成功返回。 |
| 3. 资料库 | 保留 10 条手册的标题、来源、阅读路线和原始入口，移除本地文件标识。资料全为线上入口时，资料架显示官方资料入口。 | 22 项资料库测试通过。Chrome 搜索 AN4899 并打开阅读指南，显示 ST 来源入口。 |
| 4. Blender 与三维模型 | 从候选包的脚本重新生成 PDV-P8103，核对真实厚度、脚和感光面。 | Blender 4.5.15 导出 10 个网格，生成的 GLB 与候选包内文件 SHA-256 相同。Chrome 加载该模型并点中感光面。 |
| 5. 选中与拖动换孔 | 复测选择真实 3D 板身、放到有效孔位、查看接线变化及撤销。 | Blue Pill 从 C/G 排第 6 列拖到第 9 列。确认前显示 A21 与 J24 的接线变化。确认后一次撤销恢复原电路。挡件腾位也单独确认。 [接线变化截图](qa/github-board-review.jpg) |
| 6. 键盘选孔与旋转 | 方向键从原插位或最后点选的孔起步。键盘预览与鼠标悬停分开。旋转仍限于实验台画布，组合键与输入法事件让给浏览器。 | Chrome 3D 和二维图中，从 C/G 排第 6 列按右键直接预览第 7 列。Enter 选定，确认后换位。R、Shift+R、Esc、代码输入与系统组合键均已检查。 [键盘预览截图](qa/github-board-keyboard-3d.jpg) |
| 7. 触屏 | 复测小屏点选被板身盖住的孔、触控拖动、旋转提示及撤销。 | 390 × 844 触控模拟下，3D 和二维图均能点选 C9 并确认。滑出再滑回不会当作选孔。触屏旋转可取消，拔下转 90° 后也可撤销。 [触屏截图](qa/github-hole-picker-3d-mobile.jpg) |
| 8. 代码改变硬件 | 实际编译 Blue Pill C 源码，遮挡光敏电阻并改阈值。Pico 加载两份原生 UF2 对照 PWM。 | Blue Pill 遮挡后 ADC 由 2484 降到 173。恢复照度后，只把阈值从 2000 改到 2800，ADC 仍为 2484，LED 由 0 变为约 3.618 mA。Pico 触屏在相同接线下比较了 25% 和 75% 占空比及同一时刻的电压与电流。 |
| 9. 工程往返 | 从浏览器下载 JSON，换孔后重新导入，并撤回导入。 | 导入预览保留第 7 列。确认后恢复第 6 列、源码与三根线，撤回导入回到第 7 列。 |
| 10. 整包回归 | 默认并行测试中一个编译用例未通过，发布副本的 `npm test` 改为依次运行用例。检查静态子路径和压缩包文件边界。 | 801 项通过，0 失败、0 跳过。在 `/lab-demo/` 子路径完成工程往返和资料浏览，未发现脚本异常或失败的本地资源请求。 |

触屏结果来自 Chrome 触控模拟。原生固件和电气数值来自浏览器仿真。
