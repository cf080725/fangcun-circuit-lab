# 第6轮：元件属性、诊断与撤销

## 发现与实际修改

- 原数值编辑直接转 Number 并写入，负阻值、空输入等可能污染电路；现在使用参数元数据验证，明确单位、上下界和未应用原因。0 V、0 lx 是有效值，不再用真假判断回退。
- 电位器每次滑块 input 都创建撤销记录；现在同一拖动只记录一次起始状态，change/blur 后结束一次操作。
- 元件参数与连接缺少对应关系；现在显示实际元件编号、参数、可用测量量和每个引脚真正连接的端点，端点可直接定位。
- 模型已有正向压降、NTC B 值、电机惯量等参数，界面却没有入口；现在合并电气模型参数表生成字段，不再只显示旧八类元件的固定表单。
- 自动语法检查产生的 warning 未合并到诊断面板；现在代码、运行、电路结果统一去重并按严重程度排列，显示原因、下一步及文件/元件定位。
- “漏开 GPIO 时钟”故障练习修改代码，旧撤销只恢复电路；现在代码类故障记录源码快照，恢复默认实验也可撤回。供电/BOOT0 操作进入撤销历史。
- 按键属性增加键盘 Space/Enter 及 pointer cancel/blur 释放，避免假性持续按住。

## 验证

`tests/inspector-tools.test.mjs` 4项通过：参数上下界与0值、比例换算和元数据、接线两端追踪、静态/运行诊断合并去重。

真实浏览器中已验证 ADC 旋钮到0%、adcValue=0、一次撤销恢复100%；整体UI也已验证-2Ω未应用并显示错误、修正后恢复有效、时钟故障定位和撤销恢复RCC源码，详见第10轮。诊断没有被描述为所有实物故障的穷尽检测。
