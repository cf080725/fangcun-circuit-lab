# 第 4 轮审查：接线、拖动、取消和键盘操作

日期：2026-11-06  
范围：工作台的三个渲染/共享模块，以及独立的交互决策回归测试。未修改主应用历史栈、求解器、板卡 profile 或根布局样式。

## 发现与修复

| 真实问题 | 实质修改 | 结果 |
| --- | --- | --- |
| `beginReconnect()` 建立重接状态后，从针脚开始拖动会新建一个没有 reconnect 身份的 gesture，最后误走新建导线回调。 | 把待接起点、点击端点和被移动的导线端分别保存；两视图使用同一个 `wireGestureState()`。`connectionPlan()` 校验后只发 `onReconnectWire(id,end,endpoint)`。 | 重接 A/B 端始终保留对应导线 ID 和固定另一端。点击与拖动采用同一决定过程。 |
| 重接时没有排除同点回路、重复导线或已被外部操作改变的旧导线；掉到空白后没有明确解释。 | 共享连接校验拒绝同端点、双向重复、已变化的旧线及不存在的端点；不触发变更回调，显示原因并保留可重试的起点。 | 不会因一次失误新增错误导线或耗费撤销记录，原连接保持不变。 |
| `setCircuit()` 可以在旧拖动仍存在时重绘；SVG 继续应用旧 preview，3D 保留已移除对象的拖动引用。 | 外部重绘前先撤销临时手势、释放按键、清除临时线，再构建新视图。主动释放与意外丢失 pointer capture 区分，取消先清状态后释放捕获，防止重复提交。 | 撤销、导入、参数重建后，旧拖动不能再次提交。失焦、Esc、pointercancel 和丢失捕获会结束操作。 |
| 图内的缩放工具和徽标会压住底部丝印；新建接线提示若突然占空间，也会让画布在手势中缩放。 | SVG/3D 都采用画布、固定高度状态行、独立控制底栏。状态区固定预留 48 px，控件高度 38 px、文字 13/14 px；控制区不覆盖画布。 | 提示出现时画布不跳动；缩放、方向平移、适配按钮有明确点击区。窄屏底栏会换行，实际可视高度由根代理现场评估。 |
| 临时线只说明起点，没有清楚写出吸附到哪个相邻针脚；缩小时提示圆点随图一起缩小。 | 固定状态行展示起点 → 目标端点 ID / 电压，错误目标显示原因；SVG 临时线和终点环使用屏幕尺寸描边/半径，目标、起点、可用端点分别标记。小针距提示先放大。 | 面对密集针排可以先核对目标名称，再松手确认。放大的命中范围不会穿透其他元件壳体去吸附背后的面包板孔。 |
| 图形没有可用的逐针键盘流程；重建后焦点丢失；触屏上黑色按钮帽较小，容易混淆按压和拖动。 | 默认 SVG 增加元件、导线、针脚可访问名称和焦点提示；[ / ] 切换对象，P 进入针脚，方向键选邻近可见针脚，Enter 接线。选中按钮可 Space 按住，底栏另有原生“按住按键”供触屏。 | 黑帽按压、金属底座拖动、移动模式拖黑帽分别处理；按键释放、取消及失焦都会发出 false。底栏按压控件不改变画布布局。 |
| 适配视图给每个元件固定 2.6×3.6 cm 包围框，旋转大模块后会裁掉接点；开发板/面包板在移动模式也只会平移视图。 | `componentBounds()` 计入元件本体、引脚、文字和旋转；自定义多针模块按实际高度计算。移动模式允许拖板卡/面包板，预览只改内部几何。 | 适配可容纳旋转的大模块；拖动完成只调用一次 `onMove`，共享电路对象在回调前保持原样，便于根应用建立撤销快照。 |
| 删除或重建后渲染器仍可能持有不存在的选择 ID，切换视图后出现无意义的高亮。 | `selectionDescriptor()` 保留存在对象的 ID 和类型，移除已不存在的选择；SVG 在重建后恢复仍存在的键盘焦点。 | 根应用传回同一个有效 ID 即可保持选择含义。主应用撤销前主动清空检查器选择的问题由根代理第 6 轮处理。 |

## 默认 SVG 操作约定

- 鼠标：拖元件移动；拖引脚连线；连线模式也可点两端；选线后拖 A/B 圆环重接。
- 按键：黑帽按住；底座拖动；移动模式或 Alt 拖帽盖不会按下。也可使用底栏“按住按键”。
- 键盘：`[` / `]` 选择元件/导线；`P` 或元件上的 Enter 进入针脚；方向键浏览针脚；Enter/Space 确认接线；Esc 取消。
- 元件已选、焦点不在针脚时：方向键微移 0.05 cm，Shift 加速为 0.254 cm，R 旋转 90°，Shift+R 反向。
- 导线已选时：A/B 选择重接端，Delete/Backspace 删除。重复的根层删除事件已阻止冒泡。
- 两指：在 SVG 画布内缩放/平移；单指在元件/引脚上操作。外部触控操作不沿用旧拖动。
- API 保持兼容：`setCircuit/update/setMode/home/top/setSelected/resize/dispose/setView/getView/cancelInteraction/beginReconnect`；回调签名保持原样。没有增加主应用必须接入的新接口。

## 验证证据

- `node --check` 三个渲染模块全部通过。
- 新增 `tests/renderer-interactions.test.mjs`，**12 项通过**，包含重接身份、点击/拖动起点、同点/重复/旧状态保护、不修改共享电路、选择保留、按钮意图、板卡移动、键盘邻近针脚与旋转模块适配。
- 与第 3 轮模型测试合跑，**20 项通过，0 失败**。
- 这些是纯逻辑/几何测试，不能代替真实浏览器的坐标、焦点、布局、鼠标捕获和触屏事件验证。最终 UI QA 由根代理统一执行，本轮没有额外打开浏览器。
- WebGL 仍受实际浏览器能力限制；本轮没有声称完成 3D 视觉验收。SVG 是完整键盘接线的主操作视图；3D 保留观察、鼠标操作、方向键移动、R 旋转、按钮 Space 操作及取消能力。

## 根代理最终 UI 检查点

1. 先选一根线，点击主界面重接 A/B，再从另一个针脚拖到第三个针脚；线数不增加，原 ID 不变。
2. 拖元件过程中按 Esc 或触发撤销，确认松手不再次移动；按黑帽后离开/取消/失焦确认及时释放。
3. 选中按钮后查看底栏原生按压按钮，确认出现时画布尺寸不变化。
4. 用 [ / ]、P、方向键、Enter 完成接线，确认工具按钮后焦点可返回画布，取消和删除无重复历史。
5. 放大/缩小后查看目标名称与高亮；板卡/面包板移动模式有效，观察模式仍用于平移。
6. 隐藏或移动根层旧 `.scene-overlay` 重复说明，避免它覆盖新的状态栏；以窄屏实测剩余画布高度。
